# 挖掘机项目早期测试与环境准备记录 (v0_preWork)

本目录（`v0_preWork`）主要用于归档项目早期的环境配置说明、通信协议预研脚本、正运动学调试脚本以及一些临时补丁文件。
这些文件在项目的演进过程中起到了验证和过渡的作用，目前已经完全被封装到 `v1` 至 `v11` 的正式架构中。**在实际的系统运行中，不再需要调用这些脚本。**

## 目录文件说明

### 1. 正运动学与坐标转换测试脚本 (FK Tests)
在开发 `v10_cailbration` 的正运动学模型（`kinematics.py`）时，为了验证大臂、小臂、铲斗在笛卡尔坐标系下的轨迹插值与角度偏置计算是否正确，编写了以下测试脚本：

- `check_frames.py`
  - 作用：读取 JSON 剧本（如 `test3.json`）并逐帧解析，使用 V4 的正运动学函数打印出机械臂末端（铲斗尖、小臂尖）的 2D 坐标系位置，用于排查动画生成过程中的跳帧或错位问题。
- `print_angles.py`
  - 作用：用于排查传感器原始读取角度、加上偏移量后的绝对角度以及在 UI 上可视化的相对角度之间的数学关系。打印了机械臂首尾两帧的 L1/L2 坐标及各关节角度差。
- `test_fk.py`
  - 作用：单纯测试 L2（大臂上段）在 0.7 到 47.3 度插值过程中的运动学正解输出。
- `test_fk2.py`
  - 作用：模拟“旧版逻辑”下的错误正向运动学表现（旧逻辑在计算小臂位置时未累加大臂角度），用于对比修复前后的坐标差异。
- `test_fk_angles.py` & `test_fk_angles_old.py`
  - 作用：对比新旧逻辑下，各传感器原始角度与绝对物理偏置（如 `fk.offset_boom`、`fk.offset_arm`）结合后算出的最终姿态角差异。

### 2. 闭环控制逻辑临时修补脚本
- `patch_angle_controller.py`
  - 作用：这是一个使用 Python 字符串替换的自动补丁脚本。用于在早期快速修改 `v4_control_closed/angle_controller.py` 中的遇阻智能纾解逻辑（如铲斗卡死自动推小臂）以及 `ramp_down` 柔性刹车逻辑。现已废弃，相关逻辑已直接合入 V4 源码。

### 3. CAN 通信预研与模拟脚本 (CAN Tests)
在开发 `v1_control_base` 之前，用于解析中盛 CAN 板 PDF 手册并验证基础报文收发的脚本集：
- `can_115200.py` & `can_controller.py`
  - 作用：早期的串口 CAN 收发测试框架，包含构建 13 字节中盛协议帧、测试多路继电器状态等硬编码用例。现已被 `v1` 目录下的 `zs_excavator_controller.py` 取代。
- `extract.py`
  - 作用：借助 `pypdf` 库提取《数字量输入输出系列使用手册(CAN版).pdf》中的文本内容，用于辅助编写通信协议。
- `import can.py`
  - 作用：早期的 `python-can` 库虚拟总线测试示例，因命名不规范易导致循环引用报错而废弃。
- `interactive_test.py`
  - 作用：一个终端交互式的 CAN 设备调试工具，用于逐个盲测通道和模拟量，找出现场继电器与动作的对应关系。
- `mock_device.py`
  - 作用：在没有真实 CAN 硬件连接的情况下，利用 `virtual` 接口在电脑本地模拟一个中盛控制板，用于离线跑通上位机的控制代码。

### 4. 现场网络与系统环境配置说明
这些文档记录了工控机、网络摄像头、交换机的初始化配置步骤：
- `camera_direct_connect_ubuntu.md`：记录如何在 Ubuntu 下直连并拉取摄像头的 RTSP 视频流。
- `switch_network_setup.md`：记录了网络交换机与多个网络相机的固定 IP 规划（如 `.102`、`.103`）。
- `readme_ubuntu.md`：记录了 Ubuntu 基础环境（包括串口权限、UDEV 绑定等）的初始化备忘。
