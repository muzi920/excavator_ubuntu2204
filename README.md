# 挖掘机模型控制与传感器测试系统

本仓库包含了一套完整的挖掘机模型控制与传感器数据采集系统。该项目主要用于基于 CAN 总线的设备控制（包括底层数字量/模拟量控制）、模型挖掘机的自主甩方预编程动作执行，以及基于串口的倾角传感器等设备的数据采集。

项目按功能模块分为 `v1`、`v2`、`v3` 三个子文件夹：

- **v1：** 挖掘机底层控制与基础 GUI (已整理完成)
- **v2：** 简易挖掘机自主甩方预编程程序
- **v3：** 传感器数据测试与采集（目前包含倾角传感器）
- **v4：** 基于倾角传感器反馈的闭环角度控制

---

## 📁 目录结构与使用说明

### 1. `v1/` - 基础控制与交互界面
该目录包含了与硬件（中盛 ZS-USB-CAN 转接板 + 继电器/模拟量模块）直接通信的底层控制类，以及一个用于实时交互测试的 GUI。

- **`zs_excavator_controller.py`**:
  底层核心控制库。负责将大臂、小臂、铲斗、回转、底盘的前进后退等逻辑，打包成中盛 13 字节 CAN 协议，下发到硬件。它还处理了 3 路模拟量（推力/流量）的换算与缓存。
- **`zs_excavator_gui.py`**:
  基于 `Tkinter` 的图形化交互界面。提供了滑动条来实时调节通道模拟量（0-5000），并通过 UI 按钮映射挖掘机动作（如：按住执行，松开停止）。

**使用方式：**
```bash
# 启动基础控制 GUI
python v1/zs_excavator_gui.py
```

---

### 2. `v2/` - 自主甩方预编程控制
在 `v1` 基础控制之上，该目录引入了时间维度，实现了一个动作调度器（Scheduler）。它允许将挖掘机的各个动作按照“动作+执行时间”组合成序列，实现“一键执行”连续动作。

- **`action_scheduler.py`**:
  引入了 `ActionScheduler` 类。它负责接收指定的控制动作和时间参数，通过多线程方式控制执行和停止，避免阻塞。
- **`action_gui.py`**:
  带有时序控制和日志记录的进阶 GUI。
  - **单步测试**：用户可以设定每个动作的持续时间（如 0.5s），点击按钮后机器会自动执行该动作并在到时后自动停止。
  - **预设序列执行**：内置了一套整理好的甩方动作序列（含 17 个连续动作）。用户可以通过点击“执行下一步”按钮，按顺序步进执行整个挖土甩方流程。

**使用方式：**
```bash
# 启动带有预编程序列与时间调度的 GUI
python v2/action_gui.py
```

---

### 3. `v3/` - 传感器测试与数据采集
该目录专门用于读取外围传感器的数据，用于后续的闭环控制或状态监控。目前主要包含维特（WIT-Motion）系列倾角传感器的测试代码，以及整合了动作控制的混合界面。

- **`readRad.py`**:
  倾角传感器多串口采集基础脚本。能够同时打开四个独立的串口，分别对传感器进行 Modbus 轮询，实时打印解析出的横滚角 (Roll) 和俯仰角 (Pitch)。
- **`sensor_action_gui.py`**:
  综合了 `v2` 动作控制与 `v3` 传感器数据采集的**图形化测试工具**。用户可以在左侧面板触发机械臂运动，并在右侧面板实时监控角度数据，自动或手动打点记录。

#### 📐 关节夹角计算原理 (sensor_action_gui)
在 `sensor_action_gui.py` 中，程序通过同时读取两个相邻部件的倾角传感器数据，计算它们之间的相对夹角差值，以此来评估机械臂的运动范围。

1. **使用的轴向数据**：
   - 铲斗、小臂、大臂的俯仰运动主要体现在 **Y 轴 (Pitch 俯仰角)**。因此程序提取每个传感器的 `AngY` 值进行计算。
   - 回转运动主要体现在 **Z 轴 (Yaw 偏航角)**。程序提取回转传感器的 `AngZ` 值进行计算。

2. **夹角关系计算**：
   程序直接计算相邻部件传感器 Y 轴 (Pitch) 角度的绝对差值。例如：
   - `铲斗与小臂夹角 = abs(铲斗.Pitch - 小臂.Pitch)`
   - `小臂与大臂夹角 = abs(小臂.Pitch - 大臂.Pitch)`
   - `大臂与回转夹角 = abs(大臂.Pitch - 回转.Pitch)`
   
3. **极限落差测算**：
   在 GUI 中，用户可以将机械臂分别运动到两个极限位置（例如完全伸展与完全收缩），分别点击“记录极限状态 1”和“记录极限状态 2”。
   点击“计算极限落差”后，程序会自动计算出两个状态之间各项相对夹角的差值，从而得出每个关节的**最大物理活动范围**。

**使用方式：**
```bash
# 启动动作与传感器混合测试 GUI
python v3/sensor_action_gui.py
```
*(提示：按 `Ctrl+C` 或关闭窗口可以安全停止读取并自动释放所有串口句柄。)*

### 4. `v4/` - 闭环角度控制
该目录是基于 `v1` 和 `v3` 结合的进阶控制方案。它彻底放弃了 `v2` 中盲目的“基于时间的开环控制”，改为接收用户的目标角度指令，并根据倾角传感器的实时反馈，自动控制机械臂运动直到目标角度（闭环寻的）。

- **`angle_controller.py`**:
  闭环控制器核心逻辑。负责在后台比对当前计算角度与目标角度的差值，并决定机械臂的运动方向。到达容差范围内（默认 2°）自动停止。
  - **预留接口说明**：在该脚本内部的 `__init__` 函数中，预留了 `joint_limits`（运动量程保护）字典。在您通过 `v3` 测试出各关节真实落差极值后，可以将这些最大、最小值填入，防止后续指令超出物理机械极限。
- **`closed_loop_gui.py`**:
  闭环测试交互界面。上方实时显示各个关节的相对夹角和偏航角；下方提供目标角度输入框。用户输入目标角度后点击“开始移动”，挖掘机将自动寻的。

**使用方式：**
```bash
# 启动基于传感器反馈的闭环角度控制 GUI
python v4/closed_loop_gui.py
```

## 🛠 环境依赖

在使用本套件前，请确保您的 Python 环境中安装了以下核心依赖库：

```bash
pip install pyserial
```

*注：在 `v1` / `v2` 阶段若涉及真实的 CAN 接口库，可能还需要安装 `python-can`。具体视实际硬件和系统环境而定。*
