# V9: ROS 2 导航与路径规划 (Navigation)

本目录为挖掘机的自动驾驶、底盘移动和高级环境建图与路径规划模块的预留和集成区域。目前主要集成了标准的 ROS 2 Navigation 堆栈。

## 目录结构

1. **`navigation2/`**
   - **作用**：包含了开源的 `nav2` 源码堆栈（如 `nav2_amcl`, `nav2_costmap_2d`, `nav2_planner`, `nav2_controller` 等）。
   - **用途**：这是为挖掘机底盘引入 2D 激光雷达（如 V5 中的 M300）后，实现自动建图（SLAM）、避障（Costmap）、全局路径规划和局部跟随的基石。

## 未来开发计划

- 将 `v1` 库中的 `drive_forward` 等底层底盘控制封装为 ROS 2 的 `cmd_vel` 订阅节点。
- 配置 `nav2_params.yaml`，调整挖掘机履带底盘的运动学模型和成本图膨胀半径。
- 融合 `v5` 激光雷达的点云数据和 `v3` 回转倾角数据，确保挖掘机在转动时仍能正确感知环境障碍。
