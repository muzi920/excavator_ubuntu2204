# 挖掘机模型控制与传感器测试系统 - Ubuntu 迁移交接文档

## 1. 项目背景与当前进度
本项目是一个完整的挖掘机模型控制、传感器采集与点云可视化的演进项目。
最初在 Windows 环境下开发测试，目前功能已按 `v1` 到 `v5` 进行模块化演进：

- **v1：底层控制**（CAN 协议解析、中盛硬件控制接口、模拟量映射）。
- **v2：开环调度**（基于时间的时序控制、GUI 预编程动作甩方）。
- **v3：传感器接入**（集成官方 WIT-Motion SDK，多线程串口读取 4 个倾角传感器的数据，测试各关节活动极限角度）。
- **v4：闭环控制**（结合 v1 与 v3，根据设定的目标角度，自动寻的并限制物理极限）。
- **v5：激光雷达**（集成蓝海光电 LDS-M300 雷达，纯 Python UDP 协议点云接收与二维实时 GUI 显示）。

**本次交接目的**：将本工程完整迁移至 **Ubuntu 22.04** 系统中运行。以下为接手的智能体/开发者需要注意的环境差异与适配重点。

## 2. 核心网络与硬件配置清单

### 2.1 蓝海光电 M300 激光雷达 (v5)
雷达采用 UDP 组播/点对点上传点云。
- **雷达 IP**：`192.168.158.98`
- **雷达端口**：`6543`
- **主机接收 IP**：`192.168.158.15` （Ubuntu 本机网卡必须配置此固定 IP）
- **主机接收端口**：`6668`
- **当前脚本**：`v5/lidar_viewer.py` 已经从串口重构为 UDP 接收协议，无需修改逻辑，只需确保 Linux 防火墙放行 UDP `6668` 端口。

### 2.2 维特倾角传感器 (v3 / v4)
Windows 下测试时使用的串口号分别为 `COM7` / `COM8` / `COM11` / `COM12`，波特率 `230400`。
- **迁移适配点**：在 Ubuntu 下，串口名称会变为 `/dev/ttyUSB0`、`/dev/ttyUSB1` 等。
- **操作建议**：需要编写 `udev` 规则固定传感器串口，或者在 GUI 启动前通过 `ls -l /dev/ttyUSB*` 重新确认端口映射。同时，必须将运行代码的用户加入 `dialout` 用户组以获得串口读取权限：
  ```bash
  sudo usermod -aG dialout $USER
  ```

### 2.3 挖掘机底层控制 CAN 模块 (v1 / v2)
原 Windows 环境下，控制串口为 `COM5`。
- **迁移适配点**：同倾角传感器，需要改为对应的 `/dev/ttyUSB*` 或 `/dev/ttyACM*`。

## 3. Python 环境与依赖 (Ubuntu 22.04)

Ubuntu 22.04 默认自带 Python 3.10。在运行相关脚本前，请配置虚拟环境或直接安装以下依赖：

```bash
# 更新并安装 python3-pip 和 tk 库支持 (GUI 必备)
sudo apt update
sudo apt install python3-pip python3-tk

# 安装串口库
pip3 install pyserial
```

*注意：`v3` 中的 WIT-Motion SDK (`device_model.py`) 使用了多线程与 `pyserial` 进行收发，已在 Windows 下排除了因线程冲突导致的串口卡死问题（使用了 `os._exit(0)` 暴力回收）。在 Linux 下退出机制表现通常更好，但仍需留意 `Ctrl+C` 时的守护线程退出情况。*

## 5. 给接手智能体的建议（Next Steps）

1. **处理串口映射**：接手后第一步，建议全局搜索 `COM` 关键字，提供一个 `config.json` 或修改 `v3/sensor_port_mapper_gui.py` 的串口扫描逻辑，让其支持 Linux 的 `/dev/tty*` 模式。
2. **测试 UDP 通信**：运行 `v5/lidar_viewer.py` 前，通过 `ip a` 或 `ifconfig` 验证 `192.168.158.15` 是否已绑定到网卡。若未收到数据，使用 `sudo tcpdump -i <网卡名> udp port 6668` 检查是否真的有包到达。
3. **完善闭环极值**：用户之前在 `v3` 已经准备测试机械臂的物理角度极值，接手后可提醒用户完成极值测试，并将数据填入 `v4/angle_controller.py` 的 `joint_limits` 字典中。
