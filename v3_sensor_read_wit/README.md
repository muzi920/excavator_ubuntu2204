# v3: 传感器数据测试与采集

本目录专门用于读取和处理外部传感器数据，主要针对**维特（WIT-Motion）系列倾角传感器**（型号 WT901C485 等）。该部分功能为挖掘机模型从开环走向闭环控制提供了关键的感知反馈。

## 核心脚本

### 1. `readRad.py`
基础的传感器串口轮询脚本。
- **多设备并发**：基于维特官方 Python-SDK 封装，能够同时打开 4 个串口（分别对应大臂、小臂、铲斗、回转传感器）。
- **实时解析**：在后台线程中利用 Modbus 协议高频读取保持寄存器，实时解析出各关节的 Roll（横滚）、Pitch（俯仰）、Yaw（偏航）角度，并打印在终端。

### 2. `sensor_port_mapper_gui.py`
**传感器 COM 口识别工具**。
当拔插 USB 导致 COM 口发生变化，或是无法分辨哪个串口对应哪个物理关节时使用。
- **自动枚举**：自动扫描电脑当前可用的 COM 口，用户勾选后一键连接。
- **动态变化显示**：不仅显示实时角度，还能设定当前状态为基准，显示角度的**相对变化量（ΔPitch / ΔRoll）**。用户用手晃动某一个传感器时，观察哪个卡片的数值跳动最剧烈，即可轻松识别，并在 UI 上将其直接重命名标记为大臂/小臂等。

### 3. `sensor_action_gui.py`
**动作与传感器综合测试 GUI**。
将 `v2` 的动作下发功能与倾角传感器实时读取融合在同一个界面中。
- **独立角度记录**：界面右侧实时显示 4 个关节传感器的绝对角度（重点关注大臂、小臂、铲斗的 `Pitch` 以及回转的 `Yaw`）。
- **离线模拟支持**：即使没有连接真实的挖掘机控制板，也可以在“离线模式”下运行。点击动作按钮时，只会在日志表格中打点记录起始和结束时间。
- **极限落差测算**：
  - 用户可操作挖掘机（或手动摆放）至完全收缩/完全伸展两个极限位置，分别点击记录按钮。
  - 程序会自动计算出这期间各传感器的绝对活动范围（例如 `10.0° 到 130.5°`，落差 `120.5°`），该数据对后续配置 `v4` 的闭环安全量程至关重要。

## 使用方式

**步骤 1：确认串口映射**
如果您不确定传感器对应的 COM 口，运行：
```bash
python sensor_port_mapper_gui.py
```
手动摇晃传感器完成标记。

**步骤 2：测量极限落差**
在代码中配置好正确的 COM 口后，运行：
```bash
python sensor_action_gui.py
```
在界面右下角完成“极限状态1”和“极限状态2”的记录并计算落差。
