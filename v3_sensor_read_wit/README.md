# 挖掘机 V3 倾角传感器采集与分析模块 (v3_sensor_read_wit)

本目录包含了挖掘机姿态反馈系统的核心——**Wit 标准 Modbus 倾角传感器（WT901C485）** 的读取与解析程序。这套传感器被安装在挖掘机的四大关节上（大臂、小臂、铲斗、回转底座），用于实时获取机械臂的三维空间姿态。

> **注意**: V3 仅仅负责**读取传感器数据并展示**。如果你想看基于这些数据的自动闭环控制，请前往 `v4_control_closed`。

## 文件与脚本说明

### 1. `WitStandardModbus_WT901C485-main/` (官方 SDK)
- 维特智能（WitMotion）官方提供的 Python SDK 源码。负责底层的 Modbus RTU 协议解析与寄存器通信。

### 2. `sensor_action_gui.py` (V3 动作与角度同步测试面板)
- **作用**: 这是一个非常强大的联合测试工具。它将 **V2 的手动控制功能** 和 **V3 的传感器读取功能** 结合在了一个 GUI 界面里。
- **核心功能**:
  - **同步监控**: 你可以点击界面左侧的控制按钮让挖掘机动起来，同时在右侧实时看到对应传感器角度的数值变化。
  - **极值计算**: 提供“记录极限状态”按钮。当你把挖掘机臂伸到最远和收到最近时打两个点，它可以自动帮你算出该关节的**物理活动角度范围（Pitch 差值）**。
  - **动作打点记录**: 所有手动下发的动作指令都会和当前的传感器角度一起被打在右侧的历史表格中，方便分析。
- **运行**:
  ```bash
  python3 src/shandong/v3_sensor_read_wit/sensor_action_gui.py
  ```
  *(注: 此脚本已更新为自动探测 `/dev/ttyUSB_Sensor[1-4]`，即插即用。)*

### 3. `ros2_readRad_pub.py` (ROS2 节点)
- **作用**: 将读取到的倾角传感器数据（Roll, Pitch, Yaw）实时打包成 ROS2 标准消息并发布到指定的 Topic（如 `/sensor_data`）。
- **用途**: 供其他高级规划算法或 Rviz2 可视化组件订阅和处理。

### 4. `sensor_port_mapper_gui.py` (端口映射调试助手)
- **作用**: 由于 Ubuntu 下 USB 串口插拔会导致设备名（如 `ttyUSB0`）随机变化，该工具提供一个图形界面，一键扫描当前连接的所有串口，并实时读取每个端口的传感器数据。
- **用途**: 帮助开发者快速排查“哪个 USB 口插的是大臂传感器”、“哪个插的是铲斗传感器”，从而在配置 `udev` 规则时不会弄混。

### 5. `readRad_ubuntu.py` (基础读取脚本)
- **作用**: 一个精简的命令行测试脚本。直接调用 SDK 循环读取并在终端打印传感器的三轴角度数据，用于最基础的硬件连通性测试。
