# v4: 闭环角度控制

本目录是整个项目的进阶控制方案。它彻底摒弃了 `v2` 依赖固定时长的“开环盲目控制”，而是将 `v1` 的物理控制库与 `v3` 采集到的倾角传感器数据相融合，实现了真正的**角度闭环自动寻的**。

## 核心脚本

### 1. `angle_controller.py`
闭环控制器核心大脑。
- **自动寻的（PID简化版）**：当接收到目标角度时，控制器会在后台启动守护线程，高频比对当前传感器计算出的角度与目标角度。根据误差决定是“前进”还是“后退”，一旦误差进入容差范围（默认 2°），自动下发刹车指令。
- **物理极值保护**：
  在类的 `__init__` 函数内预留了 `self.joint_limits` 字典。
  *强烈建议：在通过 `v3` 的 `sensor_action_gui.py` 测试出各个关节真实的机械极限角度后，将极小值和极大值填入此处。控制器会在每次运动前拦截超出物理范围的危险指令。*
- **传感器数据新鲜度保护**：
  闭环控制依赖实时倾角数据。控制器会检测参与计算的传感器数据是否
  “过期”。如果延迟持续超过阈值，会先急停，再中止剧本，避免在数据
  丢失/延迟时继续输出液压导致风险。
- **卡死检测与递增补偿**：
  若关节在一段时间内角度变化极小，会判定为“推力不足/卡死”。系统会
  仅对 `CH3` 采用递增补偿（每次 +200，逐步递增到上限），并在恢复运动
  后自动撤销补偿，回到剧本设定值。

### 2. `closed_loop_gui.py`
闭环测试交互界面与示教录制工具。
- **双向数据流展示**：界面上半部分实时刷新由底层传感器算出的各关节相对夹角（铲斗-小臂、小臂-大臂等）及回转偏航角。
- **目标直达控制**：下半部分为目标角度输入区。用户不再需要猜测“大臂抬起需要多少秒”，只需输入 `45` 度并点击“开始移动”，挖掘机便会自动调整姿态到达指定位置并停止。
- **剧本录制与手动示教**：支持使用实体遥控器手动调节挖掘机姿态，通过点击“📍 记录当前角度”实现物理打点示教，最终可一键导出包含目标角度、液压参数、柔性加减速时间在内的 JSON 闭环剧本。
- **初始位置标记**：对大臂/小臂/铲斗提供“🏠 记录为初始位置”，录制时会
  写入 `is_init_step: true`。执行器会对带该标记的步骤启用归位保护逻辑，
  避免在极限姿态附近因传感器读数偏差而卡死。
- **安全退出机制**：内置严格的退出与异常捕捉机制，点击关闭或在终端按下 `Ctrl+C` 时，会瞬间刹停所有动作、切断后台轮询线程并强制退出，避免串口锁死。

### 3. `run_closed_loop_script.py`
闭环剧本执行器。
- **自动解析与执行**：加载通过 GUI 录制或手动编写的 JSON 闭环剧本，依次执行每个动作步骤。
- **闭环阻塞等待**：执行器在下发动作指令后会实时监测传感器状态，直到当前关节真实到达目标角度才会执行下一步。从根本上解决了挖掘机带载工作时因阻力导致的行程误差问题。
- **柔性控制兼容**：执行器完美兼容剧本中定义的液压模拟量与三次样条柔性加减速参数，在确保精准到达目标的同时减少机械冲击。
- **分段执行与监控数据导出**：支持用 `--from-step` / `--to-step` 分段运行，
  并默认在 `logs/` 输出遥测 `telemetry_*.csv`，用于将“当前步骤、目标值、
  三关节夹角、传感器延迟、CH3 输出”等信息关联起来排查问题。

### 4. 剧本生成辅助脚本
- `generate_dig_area.py` / `generate_long_dig.py` / `generate_test3_30.py`：
  用于批量生成网格化的自动化挖掘轨迹剧本。通过计算和编排不同工作点的小臂/大臂角度以及回转时间分配，生成例如连续挖掘多轮（如 30 轮）、每次卸料在同一位置的完整 `JSON` 作业剧本。

## 参数约定（重要）

本版本仅包含机械臂与回转动作，不包含底盘移动控制。

- `CH1`、`CH2`：固定为 `0`（禁用）。
- `CH3`：液压流量控制通道，闭环控制、柔性加减速、卡死递增补偿均只
  作用于 `CH3`。

这意味着，即使旧剧本里存在 `ch1_mv` / `ch2_mv` 字段，执行时也会被
强制覆盖为 `0`。

## 剧本字段说明

- `joint`：
  - `bucket_arm`：铲斗-小臂夹角（闭环角度）
  - `arm_boom`：小臂-大臂夹角（闭环角度）
  - `boom_swing`：大臂-回转夹角（闭环角度）
  - `swing_yaw`：回转（开环时间，字段使用 `duration_s`）
- `target_val`：角度目标（仅闭环关节使用）。
- `duration_s`：回转时间（仅 `swing_yaw` 使用；正右负左）。
- `ch3_mv`：液压流量设定值。
- `ramp_up_s`：加速时间，用于起步柔性增流。
- `ramp_down_s`：减速时间，用于到位柔性泄压（消除顿挫）。
- `is_init_step`：初始位置标记；为 `true` 时启用归位保护逻辑。

## 调试与安全

<!-- prettier-ignore -->
> [!CAUTION]
> 真实设备运行时，急停必须以“下发停止指令”为准，不能用“退出程序”
> 代替。当前实现中，越限或传感器异常会先 `stop_all()` 急停，再中止剧本。

- **越限处理**：超过 `joint_limits` 会触发急停并中止剧本，避免继续执行
  后续步骤带来风险。
- **传感器延迟处理**：检测到传感器数据持续延迟，会先暂停输出等待刷新；
  超过阈值仍不恢复则急停并中止剧本。
- **CAN 打印开关**：默认不打印底层 `[TX]` 报文。如需查看 CAN 发送细节，
  运行前设置环境变量：`ZS_CAN_DEBUG=1`。

## 使用方式

**1. 手动控制与示教录制：**
在确保 CAN 转接板和四个倾角传感器都已正确连接的情况下，运行：
```bash
python3 closed_loop_gui.py
```
在界面下方填入目标角度即可观察闭环寻的过程。点击“🔴 开始录制剧本”后，可使用遥控器控制挖掘机姿态，并通过“📍 记录当前角度”完成示教打点，最后保存为 JSON 文件。

**2. 运行闭环剧本：**
录制好 JSON 剧本（如 `test1.json`）后，通过命令行即可自动执行：
```bash
# 运行指定的闭环剧本（默认执行 1 次）
python3 run_closed_loop_script.py --json test1.json

# 循环执行剧本 3 次
python3 run_closed_loop_script.py --json test1.json --times 3

# 指定其他串口并运行剧本
python3 run_closed_loop_script.py --json test1.json --port /dev/ttyUSB_Controller --times 5

# 分段执行（定位某一段动作）
python3 run_closed_loop_script.py --json long_auto_dig.json --from-step 180 --to-step 260

# 调整动作间隔（默认 0.1 秒）
python3 run_closed_loop_script.py --json test1.json --step-interval 0.1

# 指定遥测文件输出路径
python3 run_closed_loop_script.py --json test1.json --telemetry logs/my_run.csv
```
