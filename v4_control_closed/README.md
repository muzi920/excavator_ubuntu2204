## V4 角度闭环控制测试系统

本目录包含基于高精度倾角传感器和激光雷达 IMU 实现的挖掘机**纯角度闭环控制**与**自动轨迹生成**系统。通过该系统，可以实现大臂、小臂、铲斗和回转的精准位置寻的、遇阻智能补偿以及柔性软停机。

### 核心特性
- **全闭环控制**：大臂、小臂、铲斗基于倾角传感器反馈，回转基于激光雷达 IMU (Z轴角速度积分) 实时反馈。
- **智能防卡死补偿**：当液压力不足或遇阻导致角度变化停滞超 1.5 秒时，系统会自动递增自身液压（每次 +200mV，最高至 4500mV）进行突破。
- **动态重力补偿**：大臂抬起时动态补偿重力，避免起步过猛。
- **完美柔性起停**：基于距离的比例减速（距离目标越近推力越小）和基于时间的软停机（三次样条/线性泄压），彻底消除继电器急断造成的物理冲击顿挫。
- **液压死区优化**：针对比例阀 ~1300mV 的死区特性进行了算法截断与保底推力优化。

### 脚本说明

#### 1. 控制与录制工具
* **`closed_loop_gui.py`**:
  * 第一代闭环控制界面，回转仍采用“时间开环”控制。支持通过界面录制动作生成 JSON 剧本。
* **`closed_loop_gui_imu.py`** (推荐):
  * **最新一代闭环控制界面**。内部集成了 UDP 监听线程，直接读取激光雷达的 IMU 数据进行高精度积分。
  * **回转动作已完全升级为“目标角度(°)”闭环控制**。
  * 支持通过【📍 记录当前角度】按钮将当前姿态（含 IMU 回转角）直接保存至 JSON 剧本中。
* **`angle_controller.py`**:
  * 核心底层逻辑库。负责处理 PID 寻的、柔性加减速曲线、卡死检测与液压补偿、死区截断。

#### 2. 剧本执行工具
* **`run_closed_loop_script.py`**:
  * 自动读取并执行录制好的 JSON 剧本。
  * **向下兼容机制**：如果执行的是带有 `duration_s` 的老剧本，会自动降级为回转时间开环控制；如果是带有 `target_val` 的新剧本，会自动启动 IMU 监听执行高精度角度闭环控制。
  * `python3 run_closed_loop_script.py --json test3.json`

#### 3. 自动化挖掘剧本生成
* **`generate_imu_auto_dig.py`**:
  * 根据单次挖掘的模板剧本（需包含“到挖掘区”和“到卸料区”描述），自动生成扇形扫掠的高级多轮挖掘剧本。
  * `python3 generate_imu_auto_dig.py --json template_imu_dig.json --out auto_dig_imu_30_loops.json --loops 30`
* **`generate_dig_area.py` / `generate_long_dig.py` / `generate_test3_30.py`**:
  * 基于时间开环（老版本）的各类特定轨迹生成脚本。

### 运行流程
1. 确保所有传感器（`/dev/ttyUSB_Sensor1~4`）、CAN 控制器（`/dev/ttyUSB_Controller`）及激光雷达网络正常连接。
2. 运行 `python3 closed_loop_gui_imu.py`。
3. **保持挖掘机绝对静止 3 秒**，等待终端打印“陀螺仪和加速度计联合校准完成”。
4. 使用界面录制单次“挖-卸”动作并保存为模板 JSON。
5. 使用 `generate_imu_auto_dig.py` 生成多轮扫掠剧本。
6. 使用 `run_closed_loop_script.py` 执行最终自动化作业。

### 日志系统
所有控制过程的详细诊断信息（含角度、液压值、补偿触发状态、柔性刹车曲线）均会自动记录在 `logs/` 目录下，按时间戳命名，方便事后分析排障。
