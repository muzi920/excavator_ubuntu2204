# Shandong 项目 - Agent 配置

## 对话内容保存约定

由于本项目主要通过 SSH 远程连接开发，为保证对话历史的可追溯性和连续性，特制定以下保存规则：

### 保存规则

| 项目 | 约定 |
|------|------|
| **保存目录** | `/media/libo/libo_sn7100/ubuntu2204/shandong_ws/src/shandong/.agents/trae/` |
| **文件格式** | Markdown (`.md`) |
| **命名方式** | 按会话主题命名，使用中文，如 `挖掘机URDF建模.md`、`IMU预积分推导.md`、`v14接口标准化.md` |
| **保存时机** | 每次会话结束时（用户明确表示任务完成/结束对话时），一次性保存整个会话 |
| **触发语** | 用户说"保存对话"、"结束会话"、"任务完成"或类似表述时触发保存 |

### Markdown 文件结构模板

每次保存的对话文件应遵循以下结构：

```markdown
# {会话主题}

- **日期**: {YYYY-MM-DD}
- **标签**: {标签1, 标签2, ...}
- **摘要**: {一句话总结本次会话的核心内容和成果}

---

## 对话记录

### 用户
{用户消息内容}

### 助手
{助手回复内容}

### 用户
...

---

## 关键产出物

- [文件名1](file:///绝对路径/文件名1)
- [文件名2](file:///绝对路径/文件名2)

## 后续任务

- [ ] 待办事项1
- [ ] 待办事项2
```

### 标签规范

建议使用以下标签体系，便于后续检索：

| 类别 | 标签示例 |
|------|----------|
| **版本模块** | `v1_base`, `v14_urdf`, `v10_calibration`, `v11_dataset` ... |
| **技术领域** | `URDF建模`, `IMU预积分`, `逆运动学`, `点云配准`, `ROS2`, `Ceres` ... |
| **任务类型** | `课题调研`, `代码实现`, `Bug修复`, `接口统一`, `文档整理` ... |
| **硬件相关** | `挖掘机`, `机械臂`, `LiDAR`, `Realsense`, `CAN总线` ... |

## 项目背景

- **工作领域**：机器人建模（URDF）、点云处理（Ceres 配准、ROI 滤波）、轨迹规划（IK 求解）及 ROS 2 自动化控制
- **代码管理**：v1-v14 版本控制接口正按照 v14_urdf 版本进行标准化统一
- **协作习惯**：技术实现整理为"课题"形式，包含背景、目标、技术路线及数学模型推导
