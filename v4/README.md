# v4: 闭环角度控制

本目录是整个项目的进阶控制方案。它彻底摒弃了 `v2` 依赖固定时长的“开环盲目控制”，而是将 `v1` 的物理控制库与 `v3` 采集到的倾角传感器数据相融合，实现了真正的**角度闭环自动寻的**。

## 核心脚本

### 1. `angle_controller.py`
闭环控制器核心大脑。
- **自动寻的（PID简化版）**：当接收到目标角度时，控制器会在后台启动守护线程，高频比对当前传感器计算出的角度与目标角度。根据误差决定是“前进”还是“后退”，一旦误差进入容差范围（默认 2°），自动下发刹车指令。
- **物理极值保护**：
  在类的 `__init__` 函数内预留了 `self.joint_limits` 字典。
  *强烈建议：在通过 `v3` 的 `sensor_action_gui.py` 测试出各个关节真实的机械极限角度后，将极小值和极大值填入此处。控制器会在每次运动前拦截超出物理范围的危险指令。*

### 2. `closed_loop_gui.py`
闭环测试交互界面。
- **双向数据流展示**：界面上半部分实时刷新由底层传感器算出的各关节相对夹角（铲斗-小臂、小臂-大臂等）及回转偏航角。
- **目标直达控制**：下半部分为目标角度输入区。用户不再需要猜测“大臂抬起需要多少秒”，只需输入 `45` 度并点击“开始移动”，挖掘机便会自动调整姿态到达指定位置并停止。
- **安全退出机制**：内置严格的退出与异常捕捉机制，点击关闭或在终端按下 `Ctrl+C` 时，会瞬间刹停所有动作、切断后台轮询线程并强制退出，避免串口锁死。

## 使用方式

在确保 CAN 转接板和四个倾角传感器都已正确连接的情况下，运行：
```bash
python closed_loop_gui.py
```
在界面下方填入目标角度，即可观察挖掘机的自动闭环寻的过程。
