# Launch 启动脚本目录

本目录用于存放整个挖掘机系统的 ROS 2 Launch 启动文件，主要负责统一管理坐标系变换（TF）和多传感器节点的并发启动。

## 主要工作与功能

1. **统一静态 TF 树发布 (`sensors_tf.launch.py`)**
   - 构建了标准的 ROS 2 坐标系拓扑结构：规定 `map` 必须作为 TF 树的顶端父节点，结构为 `map` -> `base_link` -> `各传感器 frame`。
   - 集成了雷达的最新标定参数（包括倒装时的 Roll 翻转及 X/Y/Z 平移等），利用 `static_transform_publisher` 发布静态 TF，供 Rviz2 及后续建图算法无缝使用，且规避了时间戳异常问题。
   - 统一声明了网络摄像头、海康摄像头等其他视觉传感器相对于车体 `base_link` 的静态坐标变换。

2. **多传感器综合启动 (`all_sensors.launch.py`)**
   - 用于一键启动所有的传感器节点（如各类相机的 ROS 2 发布节点）。
   - 结合 `sensors_tf.launch.py` 一起使用，可以实现挖掘机“物理数据采集 + 空间坐标标定”的完整感知系统初始化。
