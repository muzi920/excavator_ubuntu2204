# V8: 传感器数据直接读取 (Direct Data Collection)

本目录提供了一套直接、轻量化的底层传感器读取脚本。它主要用于不依赖复杂的 ROS 2 框架，直接通过 Python 从硬件端口或网络流获取最原始的传感器数据。

## 主要脚本说明

1. **`camera_reader.py`**
   - **作用**：直接通过 OpenCV (cv2) 捕获本地 USB 或网络 RTSP 视频流数据。
   - **用途**：用于视觉数据的轻量化实时显示或抽帧保存。

2. **`inclinometer_reader.py`**
   - **作用**：直接读取安装在挖掘机大臂、小臂、铲斗和回转上的倾角传感器（例如 WIT 传感器）的原始姿态角。
   - **用途**：可以用于验证传感器健康状态或作为数据收集模块的一个直接数据源。

3. **`lidar_reader.py`**
   - **作用**：直接通过 UDP/TCP 套接字读取 M300 或其他激光雷达的原始点云数据包。
   - **用途**：避开复杂的雷达 SDK，用于定制化的数据解包和轻量级分析。

4. **`lerobot_direct_collector.py`**
   - **作用**：这是一个聚合脚本。它同时调用上述的相机、倾角、雷达读取模块，将多源传感器数据在时间戳上对齐，并直接打包。
   - **用途**：常用于需要高频、低延迟地获取多模态观测数据，以供深度学习模型推理或直接采集数据集。
